# Image Requirements for Portfolio

To complete your portfolio with the Dribbble design replica, you'll need the following images:

## Images to Add

### 1. **images/portrait.jpg** (Hero Section)

- **Dimensions:** 400x600px (minimum)
- **Content:** Your professional portrait photo (headshot)
- **Purpose:** Displayed on the right side of the hero section
- **Current file to use:** You can rename or use `IMG.jpg` or `IMG_3.jpg` from your images folder

### 2. **images/video-thumbnail.jpg** (About Section)

- **Dimensions:** 600x400px (minimum)
- **Content:** A preview/thumbnail image for a video
- **Purpose:** Shows in the About section with a play button overlay
- **Current file to use:** You can use `event1.jpg` or any other suitable image

### 3. **images/portfolio-1.jpg** through **images/portfolio-6.jpg** (Portfolio Grid)

- **Dimensions:** Each should be square (500x500px recommended) or maintain consistent aspect ratio
- **Content:** Showcase of your design projects
- **Purpose:** 6 portfolio items displayed in a 3x2 grid
- **Current files to use:**
  - portfolio-1: `EDA img.jpg`
  - portfolio-2: `task.jpg`
  - portfolio-3: `ds.jpeg`
  - portfolio-4: Use an existing image or create a placeholder
  - portfolio-5: Use an existing image or create a placeholder
  - portfolio-6: Use an existing image or create a placeholder

## How to Update Images

1. **Option A - Rename existing files:**
   - Rename your current images to match the names above
   - Update filenames in the `index.html` file if needed

2. **Option B - Create symbolic links (Advanced):**
   - Create copies of your best images with the required names

3. **Option C - Add new images:**
   - Take screenshots of your projects
   - Find or create design mockups
   - Save them with the filenames listed above

## Quick Setup

For a quick start, you can rename these files:

```
IMG.jpg → portrait.jpg
event1.jpg → video-thumbnail.jpg
EDA img.jpg → portfolio-1.jpg
task.jpg → portfolio-2.jpg
ds.jpeg → portfolio-3.jpg
```

Then create or add files for portfolio-4.jpg, portfolio-5.jpg, and portfolio-6.jpg.

---

**Note:** Once you have all images in place, your portfolio will display exactly like the Dribbble design!
